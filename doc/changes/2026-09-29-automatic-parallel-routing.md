# Automatic parallel task routing

Declared Goal work packs now route through the existing batch pool before a
canonical integration task reviews and verifies the combined result. Goal
completion requires the exact fully integrated pack, preserved evidence and a
closed integration task. Codex worktree task calls defer identity to trusted
native hooks and authenticated coordinator ancestry. Both runtime workflows use
an executable dependency/path/slot dispatcher and refill ready lanes without
waiting for unrelated siblings; batch admission also accepts actual free host
slots and leaves verification capacity available.

## Known ceiling

Dispatch results are proposals; caller must reserve against fresh host inventory
before spawning. Upgrade when a shared host reservation API exists. Native
protocol fixtures do not establish a live end-to-end batch run or measured
throughput. Missing host capabilities or lifecycle receipts remain explicit
blockers and never count as successful task completion.
